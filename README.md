### Circular Doubly Linked List

**C, Pointers, Dynamic Memory Allocation**

Implemented a circular doubly linked list using a sentinel node as part of my university programming coursework.

The implementation covers list traversal, insertion, deletion, memory management, and reversing a linked structure.

This project has helped develop my understanding of pointers, heap allocation, memory safety, and implementing data structures in C.

## Development Philosophy

I believe becoming a good programmer requires more than learning syntax or memorising solutions. Understanding the underlying logic, architecture, and decisions behind an implementation is equally important.

I try to approach programming by breaking problems into smaller components, understanding the purpose of each part, and developing solutions that are clear, efficient, and maintainable.

I also value learning through practical experience. Building applications, debugging unexpected behaviour, and revisiting previous implementations have taught me lessons that go beyond theoretical study.

As I progress through university and personal development, I want to strengthen both my theoretical understanding of computer science and my ability to apply it to real software.
